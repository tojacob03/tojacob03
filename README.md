### Hi, I'm Till/Rukawa.

I'm a data analyst who builds the tools I analyze with. Since 2019 I've worked
as an analyst and coach in competitive Clash Royale; today I build the
opponent-analysis platform that backs deck picks for Tier-1 CRL players
preparing for the 2026 World Finals.

**What I actually do:** design the data model and the analysis logic, then
build it AI-assisted (Lovable, Claude Code) and operate what I ship.

- 🔧 [rukawaanalytics.com](https://rukawaanalytics.com) - portfolio, live
  pipeline numbers, case studies
- 📄 [From Battle Log to Set Decision](https://rukawaanalytics.com/work/player-analysis-tooling) -
  how 1,000 recent battles become a deck-slot prediction
- ⚡ Also live: a German electricity price dashboard and an F1 race-strategy
  tool, both on real public data

## Open source

<a href="https://github.com/tojacob03/agentvcr"><img src="https://tojacob03.github.io/agentvcr/social.png" alt="agentvcr: replays for AI coding sessions" width="640" /></a>

- 📼 [**agentvcr**](https://github.com/tojacob03/agentvcr): replays for AI coding
  sessions. Turns a Claude Code, Codex, Cursor, Gemini CLI or OpenCode session
  into one HTML file or a link, secrets masked on your machine.
  `npx agentvcr-cli`, or [watch an example](https://tojacob03.github.io/agentvcr/demo/)
- 📈 [**Prognosebuch**](https://github.com/tojacob03/Prognosebuch): probabilistic
  day-ahead electricity price forecasts for Germany, published before the
  auction and scored in public, misses included
- 🚆 [**Letzte-Bahn**](https://github.com/tojacob03/Letzte-Bahn): how well every
  place is connected by bus and train, as travel times to doctor, supermarket,
  school and hospital
- 🧭 [**Themenkompass**](https://github.com/tojacob03/Themenkompass): who
  researches what at a university, how actively and with whom, built on OpenAlex
